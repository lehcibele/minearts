# 🌊 Mineart.s

Projeto frontend desenvolvido com **HTML, CSS e JavaScript**, inspirado na identidade visual da marca **Mineart.s**, um empreendimento artesanal de **Baía Formosa/RN**.

O projeto possui uma interface moderna, responsiva e focada na experiência do usuário, apresentando produtos artesanais, categorias, catálogo e navegação intuitiva.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando:

- **HTML5**
- **CSS3**
- **JavaScript**
- **SwiperJS** *(carrossel de produtos e categorias)*


## 📦 Biblioteca Utilizada

### SwiperJS

O carrossel do projeto foi desenvolvido utilizando a biblioteca **SwiperJS**.

🔗 https://swiperjs.com/

## ⚙️ Como Executar o Projeto

Clone o repositório:

```bash
git clone https://github.com/lehcibele/minearts.git
```

Entre na pasta do projeto:

```bash
cd mineart.s
```

Abra o arquivo:

```txt
index.html
```

ou utilize a extensão **Live Server** no VSCode.
